No endpoint configured GitHub Pages serves static files only, so this page needs a running pg_gpt2 instance to talk to. Start one and point this page at it: 
git clone https://github.com/seanwevans/pg_gpt2
cd pg_gpt2
docker compose up --build -d
docker compose run --rm provision
Then set the endpoint below to http://localhost:8000.
